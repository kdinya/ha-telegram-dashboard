# Contributing to Telegram Dashboard

Thank you for your interest in improving Telegram Dashboard!

## Development Guidelines
1. Fork the repository and create a feature branch (`feat/your-feature` or `fix/your-bug`).
2. Follow PEP 8 style conventions and run tests using `pytest`.
3. Keep commits clean and follow Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`).
4. Submit a Pull Request targeting `main`.
